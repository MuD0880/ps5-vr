*DualSense overlay for use in OBS Studio (Volcanic Red color, Skull & Co. stick)

ο This method is not a direct 'Custom CSS' or 'Edit CSS' approach, so it cannot be applied directly from gamepadviewer.com.
ο You need to open DualSense_Overlay.css in Notepad on PC Windows, copy all the contents, and paste them into OBS.

/ How to Use /
1. In OBS Studio, select 'Add Source - Browser" to create a browser.
2. Enter "https://app.gpv.gg/=1&s=5&smeter=1" in the 'URL' field.
3. The "width" is 807, and the "height" is 543.
4. Paste all the contents of the copied "DualSense_Overlay.css" into the "Custom CSS" section.
- If you want the trigger to be shown by color intensity rather than a height graph, you can remove the "&smeter=1" at the end of item.
